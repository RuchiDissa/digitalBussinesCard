# Personal Profile Card

A simple and clean personal profile card webpage built with **HTML and CSS**. This project presents a developer profile with a profile image, name, job title, and location.

## 📌 About the Project

This project was created as a beginner-friendly web development project to practice:

* HTML structure
* CSS styling
* Flexbox layout
* Image handling
* Basic responsive webpage design

The webpage displays a professional-style profile card for **Ruchira Dissanayaka**, a Full Stack Developer.

## ✨ Features

* Clean and minimal profile card design
* Personal profile image
* Developer name and job title
* Location information
* Flexbox-based layout
* Custom CSS styling
* Lightweight and fast-loading

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.

That's it — no additional installation or dependencies are required.
